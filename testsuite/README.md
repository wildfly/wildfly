# WildFly Testsuite

This directory contains the WildFly testsuite.

The documentation on how to run the testsuite, how it is structured and how to develop new tests, is maintained and published as part of the WildFly documentation:

* [WildFly Testsuite](../docs/src/main/asciidoc/Testsuite.adoc) (published at [docs.wildfly.org](https://docs.wildfly.org/))
  * [Testsuite Overview](../docs/src/main/asciidoc/_testsuite/WildFly_Testsuite_Overview.adoc) – prerequisites, testsuite modules and the profiles controlling testsuite execution
  * [Integration Testsuite User Guide](../docs/src/main/asciidoc/_testsuite/WildFly_Integration_Testsuite_User_Guide.adoc) – running the testsuite, building server configurations, parameterization and container images
  * [Testsuite Harness Developer Guide](../docs/src/main/asciidoc/_testsuite/WildFly_Testsuite_Harness_Developer_Guide.adoc) – how the testsuite harness builds and configures server instances, and how properties and debug parameters are propagated
  * [Testsuite Test Developer Guide](../docs/src/main/asciidoc/_testsuite/WildFly_Testsuite_Test_Developer_Guide.adoc) – writing tests, including Arquillian features and properties available in tests, negative and clustering tests
